BrainBolt — 500 Level Prototype

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome, Safari, Edge, or Firefox.
3. Start at Level 1 and complete levels to unlock the next level.

Features:
- 500-level progression
- Dynamic puzzle generation
- Logic, mathematics, pattern, and attention puzzles
- Difficulty scaling: Easy, Medium, Hard, Expert, Master
- Hints, timer, scoring and stars
- Saved progress using browser localStorage
- Statistics
- Dark mode
- Responsive mobile-friendly UI

Note:
This is a browser prototype. Progress is stored locally on the device/browser.
